## 1. 目标与原则

- **可重复**：测试不依赖生产数据、不依赖外部网络；数据库与缓存用 Testcontainers 启动真实实例。
- **快反馈**：单元测试秒级，集成测试分钟级；慢测试不进提交前钩子。
- **测行为不测实现**：断言接口输出与副作用，不断言私有方法。
- **越权是必测项**：数据范围与权限点属于安全边界，必须自动化覆盖。

## 2. 测试分层

| 层 | 工具 | 范围 | 运行时机 |
|---|---|---|---|
| 单元测试 | JUnit 6 + Mockito（后端）、Vitest（前端） | 领域规则、工具类、组合式函数 | 每次提交 |
| 集成测试 | Spring Boot Test + Testcontainers（PG + Valkey） | Repository、Service、事务、数据范围注入 | 每次提交 |
| 接口测试 | MockMvc / WebTestClient | Controller 契约、状态码、Problem Details、鉴权 | 每次提交 |
| 契约测试 | OpenAPI diff + 错误码注册表校验 | 接口结构、错误码一致性 | CI |
| 越权测试 | 参数化集成测试 | 每个受控表的列表 / 详情 / 导出 / 统计 | CI |
| E2E | Playwright | 登录、刷新、CRUD、权限可见性、i18n 切换 | CI（可并行） |
| 前端组件测试 | Vitest + Vue Test Utils | 组件三态、表单校验、权限指令 | 每次提交 |

## 3. 测试数据

- 统一用测试数据构造器（Builder / Factory），每个用例自建数据，不共享可变状态。
- 集成测试使用独立 schema 或每次重建；Testcontainers 生命周期由测试框架管理。
- 时间相关断言使用可注入的 `Clock`，禁止依赖 `now()` 的真实时间。
- 不使用生产数据；需要真实数据形态时用脱敏样本。
- 测试数据中的密码、令牌、手机号使用明显的假值（如 `13800000000`）。

## 4. 覆盖率门禁

| 范围 | 阈值 |
|---|---|
| 后端行覆盖率 | ≥ 70% |
| 后端新增代码覆盖率 | ≥ 80% |
| 前端行覆盖率 | ≥ 70% |
| 排除项 | 生成的 DTO/Mapper、配置类、启动类 |

覆盖率下降需要在 PR 中说明；不得用无断言测试注水。

## 5. 契约测试

| 检查 | 规则 |
|---|---|
| OpenAPI diff | 与主干快照比较，breaking change 必须显式声明 |
| 错误码注册表 | 同一 `code` 只映射一个 `httpStatus`；每个 code 中英文案齐全 |
| Problem Details | 错误响应符合 RFC 9457 结构，`type` / `code` / `traceId` 必存在 |
| 状态码契约 | 按 [03 §3](03-HTTP语义与错误模型规范.md) 校验常见场景 |
| 序列化 | 时间格式、金额字符串、枚举大写、空值规则符合 03 §5 |

## 6. 安全测试

| 项 | 要求 |
|---|---|
| 依赖漏洞 | 高危阻断；中危记录并排期 |
| 许可证 | 黑名单阻断（见 01 §3） |
| SBOM | 每次发布产出并归档 |
| 越权矩阵 | 普通用户 / 跨组织用户 / 无权限角色三类身份，覆盖受控表四类接口 |
| 认证 | 锁定、令牌过期、refresh 复用、MFA 绕过 |
| 上传 | 伪造扩展名、SVG 脚本、超大文件、双扩展名、路径穿越 |
| 敏感信息 | 响应与日志中不出现密码、令牌、完整证件号 |

## 7. CI 流水线

```text
提交 / PR
  → 代码格式检查（Spotless / Prettier）
  → 静态检查（Checkstyle / SpotBugs / ESLint）
  → 类型检查（vue-tsc）
  → 单元测试
  → 集成测试（Testcontainers）
  → 契约与错误码校验
  → 架构规则（ArchUnit）
  → 构建产物（jar / dist）
  → 许可证与依赖漏洞
  → SBOM 产出
  → E2E 冒烟（可与上一步并行）
  → 合并准入
```

任一环节失败即阻断合并；不允许跳过门禁合并。

## 13. 短信服务测试（ADR-022）

| 维度 | 要求 |
|---|---|
| 单元 | 号码规范化与国家白名单、模板变量映射与缺失校验、locale 回退、场景化频控、错误码映射、AES-GCM 加解密与密钥环版本、退订关键词匹配、群发状态机与预算/日限额、验证码错误次数 |
| 集成 | 服务商配置密文读写与掩码回显、重新加密、发送日志与回执只增、回执按最新状态查询、上行写入与自动退订、群发导入预校验与唯一约束去重、worker 分布式锁与限速、保留期清理 |
| 契约 | 厂商调用使用假 HTTP 服务或 SDK 桩，断言请求参数与签名、超时、重试与错误映射；**禁止在测试中发送真实短信** |
| 安全 | 密钥不出现在响应/日志/错误 detail；回执与上行回调的签名、时间戳、IP 白名单、限流与幂等 |
| 前端 | 配置表单、模板绑定、CSV 导入校验、群发进度、日志与退订页面 |

质量门禁：新增代码覆盖率 ≥ 80%；短信相关错误码各语言文案齐全；回调端点纳入安全测试清单。

当前基线：后端 274 个测试（228 单元 + 46 集成），行覆盖 84.3%、分支覆盖 61.3%；前端 248 个测试（shared 40 + portal 53 + admin 155）。

## 14. 审计日志测试（ADR-023）

| 维度 | 要求 |
|---|---|
| 单元 | 字段 diff（新增/删除/变更、嵌套路径、白名单、100 字段/16KB 截断、空白名单全量比较）、脱敏（键名与手机号/邮箱/证件号值规则、密钥恒 `***`、字符串化 JSON 递归、8KB 入参截断、UA 截断）、`AuditContext` 生命周期 |
| 集成 | 用户更新写 `targetId` 与 `changes`；角色授权记录权限码前后差异；系统参数记录旧值/新值且 `valueJson` 内密钥不落明文；短信服务商密钥只出现 `***`；改密/MFA 启停写审计且密钥不出现；失败回滚不写 `changes`；导出接口写 `action=export` 与 `affectedCount`；列表按目标/traceId 过滤；详情返回 `changes`、列表不返回且需 `audit:oper-log:detail`；维护脚本按保留期删除操作/登录日志 |

| 前端 | 筛选（来源/目标/traceId/HTTP 状态）、目标列、详情抽屉按需拉取与变更前后表、导出按钮权限 |
