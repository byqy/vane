## 1. 技术栈

版本以 [01 §2.2](01-技术栈与规范基线.md) 为准：Vue 3.5、Vite 8、TypeScript 7、Pinia 4、Vue Router 5、Element Plus 2.14、vue-i18n 11、axios 1.20。

## 2. 工程结构

```text
vane-web/
├─ pnpm-workspace.yaml
├─ packages/
│  └─ shared/                 # 请求层、OpenAPI 类型、i18n 公共资源、设计令牌
│     ├─ src/http/            # axios 封装、Problem Details 解析、刷新单飞
│     ├─ src/types/           # 由 OpenAPI 生成，禁止手写业务类型
│     ├─ src/i18n/            # 公共资源与 key 定义
│     └─ src/theme/           # tokens.css（--vane-* → --el-*）
├─ apps/
│  ├─ admin/                  # 后台管理端，构建 base=/admin/
│  └─ portal/                 # 前台门户端，构建 base=/
└─ package.json               # packageManager 与包管理器版本以 01 为准
```

| 应用 | 部署路径 | 说明 |
|---|---|---|
| `apps/portal` | `/` | 前台门户，语言前缀路由 `/zh-CN/…`、`/en/…` |
| `apps/admin` | `/admin/` | 后台管理端 |

部署映射与 Nginx fallback 见 [01 §4.2](01-技术栈与规范基线.md)。

## 3. 路由与权限

- 菜单与路由**由后端下发**：`GET /api/v1/auth/me` 返回用户可见的菜单树（由代码目录 `PermissionCatalog` 的 MENU 节点按已授权权限码过滤生成）。
- 前端只做**展示层过滤**，不承担安全职责；接口权限一律服务端校验。
- 路由守卫：未登录 → 登录页；已登录但无路由权限 → 403 页。
- 按钮级权限用指令 `v-permission="'iam:user:create'"`，无权限时移除节点而非隐藏。
- 权限点编码规范：`模块:资源:动作`，与后端 `PermissionCatalog` 的 `code` 一致；页面展示用 `t(nameKey)`（由 code 派生）。
- 动态路由在登录后一次性注册，刷新页面时先拉取用户信息与菜单再挂载路由。

## 4. 状态管理

| Store | 职责 |
|---|---|
| `useAuthStore` | access 令牌（**仅内存**）、当前用户、权限点集合、菜单树 |
| `useAppStore` | 侧边栏折叠、主题模式、标签页（仅 admin） |
| `useLocaleStore` | 当前语言、可用语言列表 |
| 业务 store | 按模块划分，仅存放跨组件共享状态；页面局部状态留在组件内 |

约束：

- access 令牌**不得**写入 `localStorage` / `sessionStorage` / Cookie。
- store 内不发请求，由 API 层调用后写入。
- 页面刷新时通过 `/api/v1/auth/refresh`（refresh Cookie）恢复登录态，再拉用户信息与菜单。

## 5. 请求层

统一封装在 `packages/shared/src/http`：

| 能力 | 约定 |
|---|---|
| 基础地址 | `/api/v1`（与后端路径结构一致） |
| 凭据 | `withCredentials: true`（仅用于 auth 端点携带 refresh Cookie） |
| 认证头 | 自动附加 `Authorization: Bearer <access>` |
| 语言 | 自动附加 `Accept-Language` |
| 链路 | 自动附加 `X-Request-Id`（客户端生成） |
| 幂等 | 创建类 POST 由调用方传入 `Idempotency-Key`（UUID） |
| 错误 | 统一解析 Problem Details，抛出强类型错误对象（含 `code`、`traceId`、`errors[]`） |
| 401 | 单飞刷新后重放原请求；刷新失败清理状态并跳登录（见 03 §13） |
| 422 | `errors[].pointer` 映射到表单字段 |
| 分页 | 统一拼装 `page[size]` / `page[after]` 或 `page[number]`，并做 URL 编码 |

**禁止**在组件内直接调用 axios；所有请求经 `api/` 层函数。

## 6. 类型

- API 类型由 OpenAPI 文档生成（`openapi-typescript` 或等价工具），生成物进 `packages/shared/src/types`。
- **不得**手写与后端重复的接口类型；扩展字段用类型交叉，不改生成物。
- 生成物随后端契约变更在 CI 中校验。

## 7. 设计令牌与主题

```css
/* tokens.css 结构示意 */
:root {
  --vane-color-brand: #2f6bff;
  --vane-color-success: #1f9d55;
  /* ...间距、圆角、字号 */
}
:root {
  --el-color-primary: var(--vane-color-brand);
  --el-color-success: var(--vane-color-success);
  /* ...映射到 Element Plus */
}
```

约束：

- 业务样式**只允许**使用 `--vane-*` 令牌；不直接引用 `--el-*`。
- 禁止散落魔法值（颜色、间距、圆角、字号）。
- 暗色模式通过切换令牌值实现，不通过覆盖组件样式。
- 组件级样式使用 `<style scoped>`；禁止全局覆盖 Element Plus 内部类名。
- Element Plus 按需引入（ADR-016）：模板直接写 `el-*`，由 `unplugin-vue-components` 解析；`v-loading` 指令与 `ElMessage`／`ElMessageBox` 的样式需在入口显式注册。

## 8. 组件规范

| 项 | 约定 |
|---|---|
| 命名 | 组件文件 `PascalCase.vue`；组合式函数 `useXxx.ts` |
| 写法 | `<script setup lang="ts">` + `<template>` + `<style scoped>` |
| Props | 显式类型 + 默认值；复杂对象用接口定义 |
| Emits | 显式声明类型 |
| 状态 | 必须处理**加载态、空态、错误态**三态，禁止只写成功路径 |
| 拆包 | 页面级组件放 `views/`，可复用组件放 `components/`；单文件超过 400 行考虑拆分 |
| 可访问性 | 语义标签、表单 `<label>`、图标按钮 `aria-label`、键盘可操作（WCAG 2.2 AA） |
| 页面内帮助 | 菜单页标题旁用 `HelpTip`（「?」按钮）打开抽屉，说明页面用途与用法；`page` 取自 `helpPages` 联合类型，文案键 `help.<page>.what` / `help.<page>.steps`（见 [ADR-019](10-ADR/ADR-019-页面内帮助.md)） |
| 字段级帮助 | 表单字段 label 插槽里用 `FieldHelp`（小号「?」）打开气泡，说明该字段填什么、有什么坑；`help` 取自 `fieldHelpKeys` 联合类型，文案键 `field.<page>.<field>.help`（见 [ADR-020](10-ADR/ADR-020-表单字段级帮助.md)） |
| 后台外壳与滚动 | 一屏布局：`html/body/#app` 高度 100% 且 `overflow: hidden`；侧边栏与主内容区各自独立滚动，顶部 header 固定不随滚动移动；长表格页的分页吸底（sticky）始终可见；禁止整页滚动 |

## 9. 国际化使用

- 所有文案经 `$t('key')`，key 命名遵循 [04 §2](04-国际化规范.md)。
- 语言切换写入用户偏好（已登录）或 `__Host-locale` Cookie（未登录）。
- 前台门户使用语言前缀路由；后台管理端语言切换不改路由。
- 日期、数字、货币一律用 `Intl.*`，禁止手写格式（见 04 §5）。

## 10. 表单与表格

- 表单校验规则与后端 DTO 校验保持一致；错误消息用 i18n key。
- 提交按钮防重复点击；创建类请求带 `Idempotency-Key`。
- 表格：分页、排序、筛选由 `useTable` 组合式函数统一封装；列宽与操作列固定规则统一。
- 导出：走独立权限点，导出前显示条数提示，导出请求不与列表共用接口。

## 11. 构建与环境

| 项 | 约定 |
|---|---|
| 环境变量 | 仅 `VITE_` 前缀；不得写入密钥 |
| base | portal `/`，admin `/admin/` |
| 构建产物 | `dist/`，由 Nginx 托管 |
| 路由模式 | history 模式，依赖 Nginx fallback（见 01 §4.2） |
| 源映射 | 生产不对外暴露 sourcemap |
| 开发服务器监听 | 同时监听 IPv4/IPv6 回环（`server.host: '::'`），避免 Windows 下 `127.0.0.1` 的连接等待约 2 秒；仅用于本机开发，不得暴露公网 |

## 14. 门户 SEO 约定

- **路由**：`/{locale}` 与 `/{locale}/{slug}`；`/` 重定向到当前语言，旧式 `/{slug}` 兼容到当前语言的内容页。
- **语言的唯一来源是 URL**：路由守卫把 `:locale` 同步到 vue-i18n；切换语言通过导航完成（保留当前页面）。
- **元数据**：页面数据加载后调用 `@vane/shared` 的 `applySeo`，写入标题、描述、canonical、OG、hreflang；404 用 `noindex`。
- **可爬取内容**：sitemap 与 robots 由后端生成；前端不生成这两份文件。
- **静态兜底**：`apps/portal/index.html` 保留默认标题与描述。
- **服务端状态**：页面未加载完成时不得把空标题写入 head，保持默认标题直到数据返回。
- **内容页面**：后台提供文章、分类、标签三个页面；文章编辑含多语言标题/摘要/正文、分类、标签与发布状态，门户列表页复用同一套分页与 SEO 约定。
- **门户首页**：公告区块 + 最新文章区块（最近 5 篇，链接文章详情与列表页）；数据随语言切换重新拉取。
- **门户公共页头**：品牌、页头导航与语言切换由 `SiteHeader` 统一提供，所有门户页面（首页/内容页/文章列表/文章详情/分类）共用，详情页不再丢失导航。
## 15. 短信服务页面

菜单「运维管理 → 短信服务」，短信模板/签名/服务商/模板绑定/群发任务/发送日志/退订名单/上行消息八个页签（短信模板可编辑全部 20 种语言正文），均沿用 `.page` + `.card` 布局与三态处理：

| 页面 | 关键内容 | 权限点 |
|---|---|---|
| 服务商配置 | 服务商列表（类型、启用、默认）、编辑对话框（AK/SK 掩码回显，留空表示不修改）、测试发送 | `ops:sms:config` / `ops:sms:send` |
| 签名管理 | 按服务商/国家/语言维护签名与启停 | `ops:sms:config` |
| 模板绑定 | 选择站内模板（channel=SMS），绑定厂商模板码、签名、变量映射（key-value 编辑器） | `ops:sms:template` |
| 发送日志 | 分页筛选（模板/服务商/结果/送达状态/号码掩码/时间）、参数展开、CSV 导出、重发 | `ops:sms:log` |
| 群发任务 | 创建活动、CSV 导入预校验（有效/无效/重复/已退订）与错误行下载、计划时间、限速与预算/日限额、进度条与统计、开始/暂停/取消 | `ops:sms:campaign` |
| 退订名单 | 退订记录（号码哈希、范围、来源、原因）、新增与移除 | `ops:sms:optout` |
| 上行消息 | 用户回复（服务商、掩码号码、内容、接收时间、是否已处理、命中关键词） | `ops:sms:log` |

约定：

- 服务商表单按 `provider_type` 动态渲染字段，保存前由后端 schema 校验。
- 密钥字段只显示掩码；输入框留空表示保持不变，输入新值才覆盖；提供「重新加密」操作（密钥轮换后使用）。
- 发送日志的「送达状态」取自回执最新状态；无回执时显示「未知」；行内可打开回执明细。
- 上行能力按服务商能力显示（如阿里云未接入 MNS 时标记「不可用」）。
- 群发导入先展示校验结果（有效/无效/重复/已退订条数），确认后才创建收件人。
- 所有时间按用户时区展示、按 UTC 提交（与 08 §8 的时间约定一致）。
- 文案键前缀 `sms.*`，随页面一并补齐 20 种语言。

## 16. 审计日志页面

菜单「审计 → 操作日志 / 登录日志」，沿用 `.page` + `.card` 与三态处理：

| 页面 | 关键内容 | 权限点 |
|---|---|---|
| 操作日志 | 筛选（模块、动作、结果、用户、来源、目标类型/ID、traceId、IP、HTTP 状态）；列：模块、动作、来源、目标（类型:名称）、方法、路径、用户、结果、HTTP 状态、耗时、IP、时间；详情抽屉按需拉取详情，展示基本信息（含影响条数）、字段级变更表（字段/改前/改后）与参数 JSON；导出 CSV | `audit:oper-log` / `audit:oper-log:detail` / `audit:oper-log:export` |
| 登录日志 | 筛选（用户、结果、时间）；列：时间、用户、结果、IP、UA、traceId；导出 CSV | `audit:login-log` / `audit:login-log:export` |

约定：

- 列表不请求 `params`/`changes`，详情按行 ID 单独请求，避免大字段拖慢列表。
- 变更表只展示发生变化的字段；`***` 原样展示并提示「已脱敏」；超过上限显示「已截断」。
- 目标列优先显示 `targetLabel`，无快照时显示 `targetType:targetId`。
- 时间按用户时区展示、按 UTC 查询；`traceId` 可复制，便于与日志/错误体串联。
- 导出动作自身也会写入审计，前端无需额外提示。
- 详情按钮仅在当前用户具备 `audit:oper-log:detail` 时显示；列表接口不下发 `params`/`changes`。

## 17. 邮件服务页面

「运维 → 邮件服务」，三个页签（权限不足的页签隐藏）：

| 页签 | 内容 | 权限点 |
|---|---|---|
| 邮件模板 | 模板列表（编码/状态/语言数，仅 EMAIL 渠道）、多语言译文编辑（列出全部 20 种语言，未填正文不落库）、测试发送 | `ops:mail` / `ops:mail:send` |
| 服务商 | SMTP 列表（地址、发件人、默认、启用、日限额）、新建/编辑（密码只写不回显）、连通性校验、删除 | `ops:mail:provider` |
| 发送日志 | 状态/模板/收件人/时间筛选、分页、详情（错误码与 traceId）、导出 CSV | `ops:mail:log` / `ops:mail:log:export` |

约定：

- 密码字段留空表示保持原值；列表与详情永不显示密码。
- 发送为异步：测试发送返回 `logId` 与渲染结果，状态以「发送日志」为准。
- 短信渠道模板在短信服务页维护（短信模板页签），邮件服务页只管理 EMAIL 模板。
