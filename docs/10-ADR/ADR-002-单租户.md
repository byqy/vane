# ADR-002：不做多租户

| 项 | 值 |
|---|---|
| 状态 | 已接受 |
| 日期 | 2026-10-17 |
| 影响文档 | 总纲 §1.2、02 §1 |

## 背景

目标客户是单个小微企业，存在多个组织（部门、门店、项目组）的数据可见性需求，但不存在「多个客户之间互相不可见」的需求。

## 选项

| 选项 | 说明 |
|---|---|
| 真多租户 | 所有表带 `tenant_id`，支持按域名/账号区分租户 |
| 单租户 + 组织树 + 数据范围 | 用组织维度做数据可见性 |

## 决策

**不做多租户 SaaS**。采用单租户 + 组织树 + 数据范围。

## 影响

- 正面：所有业务表不带 `tenant_id`，唯一索引、查询、缓存、定时任务都无需租户维度，复杂度低一个数量级
- 代价：若将来要 SaaS 化，需要全表重构与登录流程改造
