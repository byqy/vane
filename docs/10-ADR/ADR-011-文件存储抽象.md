# ADR-011：文件存储采用抽象接口 + 本地磁盘

| 项 | 值 |
|---|---|
| 状态 | 已接受 |
| 日期 | 2026-10-17 |
| 影响文档 | 02 ADM-09、01 §3.4 |

## 背景

附件与图片需要存储。直接绑定本地磁盘会让后续迁移困难，直接引入对象存储则增加部署组件与许可风险。

## 选项

| 选项 | 优点 | 代价 |
|---|---|---|
| 只本地磁盘 | 最简单 | 换存储需改代码 |
| 抽象接口 + 本地默认 | 零依赖、可切换 | 多一层接口 |
| 直接 S3 兼容 | 多实例友好 | 多一个组件，MinIO 为 AGPL |

## 决策

- 定义 `FileStorage` 抽象接口，默认实现为本地磁盘
- 预留 S3 兼容实现，按配置启用
- 不引入 MinIO；如需要对象存储，接云对象存储或 SeaweedFS（Apache-2.0）
- 部署按**单实例或共享卷**设计

## 影响

- 正面：开箱即用，无额外组件；换存储不改业务代码
- 代价：多实例部署时必须提供共享卷，否则附件不互通
