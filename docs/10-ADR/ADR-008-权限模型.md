# ADR-008：RBAC + 数据范围

| 项 | 值 |
|---|---|
| 状态 | 已接受 |
| 日期 | 2026-10-17 |
| 影响文档 | 02 §2、01 §4.3 |

## 背景

管理端需要同时回答「能不能做」与「能看到哪些数据」两个问题。小微企业普遍存在部门/门店级的数据隔离诉求。

## 选项

| 选项 | 能力 | 复杂度 |
|---|---|---|
| 纯 RBAC | 功能与按钮权限 | 低 |
| RBAC + 数据范围 | 增加数据可见范围 | 中 |

## 决策

采用 **RBAC + 数据范围**：

- 功能权限：权限点（按钮级）↔ 角色 ↔ 用户
- 数据范围：全部 / 本组织及以下 / 本组织 / 仅本人 / 自定义
- 数据范围在**查询构建阶段统一注入**；受控表登记归属列；全局查询用显式豁免注解并记审计；越权测试覆盖列表、详情、导出

## 影响

- 正面：支持组织级数据隔离，模板可直接用于多部门客户
- 代价：查询条件对开发者隐式，需维护表注册清单与越权测试；豁免机制有被滥用风险，需白名单与审计
