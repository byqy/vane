# ADR-007：不透明令牌 + Refresh 轮换

| 项 | 值 |
|---|---|
| 状态 | 已接受 |
| 日期 | 2026-10-17 |
| 影响文档 | 03 §14、01 §10 |

## 背景

认证方案需同时满足 Web 与未来 App、可即时撤销、可防令牌被盗。

## 选项

| 选项 | 说明 |
|---|---|
| 服务端会话 + CSRF | Web 最优，但 App 需双模式改造，且有 CSRF 面 |
| 不透明令牌 + Refresh | Web/App 统一，无 CSRF，需刷新机制 |
| JWT + Refresh | 无状态，但撤销需 denylist，维护成本高 |
| OIDC | 适合企业 SSO，但对模板过重 |

## 决策

采用 **不透明令牌**：

- access 15 分钟，只存内存，`Authorization: Bearer`
- refresh 7 天，`__Host-REFRESH`（Secure + HttpOnly + SameSite=Strict + Path=/）
- refresh 一次性轮换 + 复用检测 + 设备族撤销
- 服务端存 access 哈希（TTL 15 分钟）与 refresh 哈希及族状态（TTL 7 天），不存明文

## 影响

- 正面：Web/App 统一；无 CSRF；令牌可即时撤销
- 代价：前端需实现 401 单飞刷新与页面加载恢复；后端多一套令牌生命周期管理
