# ADR-014：主题采用设计令牌 + CSS 变量

| 项 | 值 |
|---|---|
| 状态 | 已接受 |
| 日期 | 2026-10-17 |
| 影响文档 | 01 §6.4 |

## 背景

模板需要支持换肤，且不应让业务代码与组件库主题变量耦合。

## 选项

| 选项 | 换肤成本 | 问题 |
|---|---|---|
| 直接用组件库默认 | 覆盖组件样式 | 升级组件库易崩 |
| SCSS 编译期定制 | 需重新构建 | 无法运行时换肤 |
| 设计令牌 + CSS 变量 | 改变量即可 | 多一层映射 |

## 决策

- 定义令牌层 `--vane-*`（颜色、间距、圆角、字体）
- 令牌映射到 Element Plus 的 `--el-*` 变量
- 业务样式**只允许**使用令牌，不直接引用组件库变量

## 影响

- 正面：换肤只改映射；业务代码与组件库解耦
- 代价：需维护约 50–80 个令牌变量，新增主题化组件时可能需补映射
