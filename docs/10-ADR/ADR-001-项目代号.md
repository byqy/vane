# ADR-001：项目代号定为 vane

| 项 | 值 |
|---|---|
| 状态 | 已接受 |
| 日期 | 2026-10-17 |
| 影响文档 | 总纲 §4、01 §4.4 |

## 背景

模板需要一个可对外传播、同时能作为 Java 包名、Maven 工件名、npm scope 前缀的代号。目标客户是小微企业，其需求经常新增与变化。

## 选项

| 选项 | 说明 |
|---|---|
| 保留占位 `tby` | 零改动，但语义不透明 |
| 语义化英文名 | 可传播，但需核查占用 |
| 团队前缀 + 语义 | 可追溯，但包名较长 |

## 决策

采用 **`vane`**（风向标）——系统本身稳定，随风向调整朝向，呼应「需求快速变化」。

- Java 包：`xyz.byqy.vane.<module>.<layer>`
- Maven：groupId `xyz.byqy`，artifactId `vane-<module>`
- npm scope：`@vane/*`

## 影响

- 正面：语义贴切；Maven 坐标与 GitHub 组织名均无占用
- 代价：npm 存在 2017 年废弃的同名包（使用 scope 可规避）；工作区目录名需另行重命名
