# ADR-003：主键采用 UUIDv7

| 项 | 值 |
|---|---|
| 状态 | 已接受 |
| 日期 | 2026-10-17 |
| 影响文档 | 01 §7.2、03 §5 |

## 背景

需要一种在单库、多环境导入、未来可能分库的场景下都不冲突的主键方案。

## 选项

| 选项 | 优点 | 代价 |
|---|---|---|
| UUIDv7 | 时间有序、跨库无冲突、不泄露数量 | 16 字节，索引大于 bigint |
| bigint 雪花 | 8 字节、有序 | 需自实现 workerId 与时钟回拨处理 |
| bigint 自增 | 最简单 | 泄露业务量、迁移困难 |

## 决策

采用 **UUIDv7**，由 PostgreSQL 18 内置 `uuidv7()` 生成，应用层不自行生成。

## 影响

- 正面：索引局部性好；数据导入与多环境合并无冲突；对外不暴露记录数量
- 代价：索引与存储略大；URL 中的标识较长
