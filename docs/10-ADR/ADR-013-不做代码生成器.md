# ADR-013：不内置代码生成器

| 项 | 值 |
|---|---|
| 状态 | 已接受 |
| 日期 | 2026-10-17 |
| 影响文档 | 02 ADM-15 |

## 背景

代码生成器能加速 CRUD 模块开发，但生成代码必须同时满足本模板的多项规范（JPA、Problem Details、数据范围、权限点、i18n）。

## 选项

| 选项 | 优点 | 代价 |
|---|---|---|
| 内置生成器 | 表多时省事 | 生成器需随规范同步维护，易产出不合规代码 |
| 外部 CLI | 不侵入主工程 | 单独维护与文档成本 |
| 不做 | 零维护、质量一致 | 新模块需手工照写 |

## 决策

**不做内置生成器**，改为提供：

1. 一个完整的示例业务模块（表、迁移、Entity、DTO、Mapper、Service、Controller、前端页面、测试）
2. 新增模块 checklist（改哪些文件、注册哪些权限点与数据范围表）

## 影响

- 正面：无生成器维护负担；新模块质量与示例一致
- 代价：模块数量很多时（数十张表）手工编写效率较低
