# ADR-015：前端采用单仓多包

| 项 | 值 |
|---|---|
| 状态 | 已接受 |
| 日期 | 2026-10-17 |
| 影响文档 | 01 §4.2 |

## 背景

前端包含后台管理端与前台门户端，两端用户、路由、依赖不同，但需共享请求层、类型、i18n 与设计令牌。

## 选项

| 选项 | 隔离性 | 构建复杂度 |
|---|---|---|
| 单仓多包 | 两应用独立构建部署 | 略高 |
| 单应用 | 同一产物，一端问题影响两端 | 低 |

## 决策

采用 **pnpm workspace 单仓多包**：

```text
vane-web/
├─ packages/shared/     # 请求封装、OpenAPI 生成类型、i18n 公共资源、设计令牌
├─ apps/admin/          # 后台管理端
└─ apps/portal/         # 前台门户端
```

## 影响

- 正面：两端可独立发布；共享层边界清晰，避免复制粘贴
- 代价：需维护 workspace 配置与两份构建；共享包变更影响两端，需版本与测试约束
