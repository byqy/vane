# ADR-005：资源式响应 + RFC 9457 错误模型

| 项 | 值 |
|---|---|
| 状态 | 已接受 |
| 日期 | 2026-10-17 |
| 影响文档 | 03 §1–§4 |

## 背景

需要一套符合 HTTP 语义、可被监控与客户端库正确处理的响应模型。

## 选项

| 选项 | 说明 |
|---|---|
| 统一信封 + 恒 200 | 实现简单，但状态码失去语义，监控、重试、缓存、认证流程全部失效 |
| 资源式 + 真实状态码 + Problem Details | 符合 RFC 9110 / RFC 9457 |

## 决策

- 成功响应直接返回资源或集合表示，不设 `code`/`msg` 外层
- 失败一律 `application/problem+json`（RFC 9457），业务码作为扩展成员
- 业务码 → HTTP 状态由错误码注册表统一决定，业务代码不手写状态码

## 影响

- 正面：状态码可驱动监控、重试、缓存与认证流程；OpenAPI 契约准确
- 代价：前端需按状态码分支；错误码注册表需持续维护
