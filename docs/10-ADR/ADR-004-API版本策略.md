# ADR-004：API 版本与路径结构

| 项 | 值 |
|---|---|
| 状态 | 已接受 |
| 日期 | 2026-10-17 |
| 影响文档 | 03 §1、03 §10 |

## 背景

需要一套在 Web、App、未来第三方调用共存时都成立的版本与路径约定。

## 选项

| 选项 | 说明 |
|---|---|
| URL 路径版本 | `/api/v1/...`，直观、易缓存与网关路由 |
| 媒体类型版本 | `Accept: application/vnd.vane.v1+json`，URL 稳定但调试与网关复杂 |
| 自定义 Header | 非标准，调试与缓存成本高 |

## 决策

- 采用 **URL 路径主版本** `/api/v1`；只有不兼容变更才升主版本
- 废弃并行期 **3 个月**，通过 `Deprecation` 与 `Sunset` 响应头声明
- 路径结构：`/api/v1/auth/*`（共用）、`/api/v1/admin/*`、`/api/v1/portal/*`、`/api/v1/public/*`

## 影响

- 正面：调试成本低；缓存与网关策略简单
- 代价：URL 中含版本号；并行期需同时维护两个版本
