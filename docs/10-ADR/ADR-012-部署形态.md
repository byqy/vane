# ADR-012：默认 Docker Compose，保留裸机 jar

| 项 | 值 |
|---|---|
| 状态 | 已接受 |
| 日期 | 2026-10-17 |
| 影响文档 | 01 §1 |

## 背景

小微企业客户的运维能力差异大：有的只有一台云服务器，有的不允许使用容器。

## 选项

| 选项 | 优点 | 代价 |
|---|---|---|
| 只 Compose | 交付一致、一键起全套 | 目标机需 Docker |
| 只 jar + systemd | 不依赖容器 | 客户需自备 PG/Valkey/JDK |
| Compose 默认 + jar 可裸跑 | 覆盖最广 | 需维护两套启动说明 |
| K8s | 弹性好 | 对小微企业过重 |

## 决策

- 默认交付 **Docker Compose**：Nginx + 应用 + PostgreSQL + Valkey
- 应用保持为**标准 Spring Boot 可执行 jar**，可裸机运行；配置经环境变量注入
- **不做 K8s**（模板范围外）

## 影响

- 正面：交付门槛低；同一份产物既能容器跑也能裸跑
- 代价：需维护两份启动与升级说明；目标机要么有 Docker 要么有 JDK
