# ADR-025：官网内容模型与门户形态

| 项 | 值 |
|---|---|
| 状态 | 已接受 |
| 日期 | 2026-10-23 |
| 影响文档 | 02 §5、03 §18、04 §6、05 §2、08 §18 |
| 关联 | 延续 [ADR-006](ADR-006-门户纯SPA.md)（SPA 路由）、[ADR-017](ADR-017-门户SEO基础.md)（URL/SEO）、[ADR-018](ADR-018-内容体系.md)（文章/分类/标签）；**不修改**以上 ADR 的结论 |

## 背景

门户当前只有「首页 + 公告 + 最新文章 + 内容页」四块能力，形态是内容管理台的自带前台，不是企业官网：

1. **没有产品这一内容类型**：官网需要产品列表与产品详情（介绍、特性、图集、视频、咨询入口），现有 `cms_page`（单页富文本）、`cms_article`（列表型内容）都不承载这类结构化展示。
2. **没有图集**：所有内容只有单个 `cover_file_id`，产品页通常需要多张图 + 一段演示视频。
3. **文件服务不支持视频**：`FileService` 白名单只有 png/jpeg/webp/gif/pdf，上传上限 20 MB，`sys_file` 没有时长与视频封面字段。
4. **导航与轮播文案只能是 i18n key**：`cms_nav.label_key`、`cms_banner.title_key` 是资源 key，后台无法填写「关于我们」这类自由文案，官网场景不成立。
5. **门户前端没有官网骨架**：每个页面各自渲染 `SiteHeader`、没有页脚、没有设计令牌（全局只有 3 个 CSS 变量）、首页只有静态 banner 网格、没有产品页、没有 `Organization`/`Product` 结构化数据。
6. **内容表全是空表**：`cms_*` 没有任何种子行，官网无法「开箱即用」。

## 决策

### 1. 产品独立建模（三张新表）

| 表 | 作用 | 关键列 |
|---|---|---|
| `cms_product` | 产品主体 | `id`、`code`（唯一）、`slug`（唯一）、`group_code`（产品线，可空）、`cover_file_id`、`video_file_id`、`status`（DRAFT/PUBLISHED/ARCHIVED）、`sort_no`、`published_at`、审计列 |
| `cms_product_i18n` | 产品多语言 | `product_id`、`locale`、`name`、`summary`、`body`（HTML）、`features`（jsonb，特性数组）、PK(`product_id`,`locale`) |
| `cms_product_media` | 产品媒体集 | `id`、`product_id`、`file_id`、`kind`（IMAGE/VIDEO）、`sort_no`、`caption`、`updated_at` |

- 与 `cms_article` 同样的「主体 + `_i18n`」模式；读取回退顺序仍是 请求语言 → `zh-CN` → 首个可用语言。
- `features` 用 jsonb 存特性条目数组（`{"title":"…","description":"…"}`），便于门户渲染成勾选清单。
- 媒体与产品多语言解耦（媒体本身无语言属性，`caption` 为运营备注）。

### 2. 导航与轮播支持自由文案（两张新表）

- `cms_nav_i18n(nav_id, locale, label)`、`cms_banner_i18n(banner_id, locale, title)`；公开 DTO 的 `label`/`title` 按请求语言取值，**回退顺序**：i18n 行 → 原 `label_key`/`title_key`（保持既有 key 方案可用）。
- 既有 `label_key`/`title_key` 列保留不变，后台表单从「只填 key」改为「可填自由文案（按语言），可留空回退 key」。

### 3. 文件服务支持视频

- 上传白名单扩展为 `image/png`、`image/jpeg`、`image/webp`、`image/gif`、`application/pdf`、`video/mp4`、`video/webm`。
- 体积上限：`vane.file.max-size-mb` 默认 200，multipart 上限同步放宽；图片仍按原上限在业务层另行校验（如需）。
- `sys_file` **不加列**：视频封面复用 `cms_product.cover_file_id`，不引入时长/转码字段（超出本轮范围）。

### 4. 公开接口（新增）

| 方法 | 路径 | 参数 | 响应 |
|---|---|---|---|
| GET | `/api/v1/public/products` | `page[number]`、`page[size]`、`group` | `PageResult<PublicProductView>`：`items[]` + `page`；item = `id,code,slug,group,coverFileId,videoFileId,name,summary,sortNo,publishedAt` |
| GET | `/api/v1/public/products/{slug}` | path slug | `PublicProductDetail`：`id,code,slug,group,coverFileId,videoFileId,name,summary,body,features[],media[],sortNo,publishedAt`；`media[]` = `{fileId,kind,sortNo,caption}` |

- 仅返回 `status='PUBLISHED' 且 deleted_at is null`；草稿/归档返回 404 `CONTENT_PRODUCT_NOT_FOUND`。
- 列表按 `sort_no asc, published_at desc`；详情按 slug 精确匹配。
- `GET /api/v1/public/navs`、`/banners` 的 DTO 增加 `label`/`title` 本地化字段（不破坏既有 `labelKey`/`titleKey`）。

### 5. 后台接口（新增）

- `GET/POST/PATCH/DELETE /api/v1/admin/products`、`POST /{id}/publish`、`POST /{id}/unpublish`（`DELETE` 为软删）；`PUT /{id}/media` 整体替换媒体集。
- 权限点：`content:product`（页面）、`content:product:media`（媒体维护）；菜单挂在「内容运营」下，排序在文章/分类/标签之后。
- 审计：产品创建/更新/发布/删除记录字段级前后值。

### 6. 门户形态

路由（全部带 `/{locale}` 前缀，语言是 URL 唯一来源，沿用 ADR-017）：

| 路由 | 页面 | 数据来源 |
|---|---|---|
| `/{locale}` | 首页 | Hero（主图/视频）+ 轮播 + 公司简介摘要 + 产品矩阵 + 核心优势 + 最新动态 + 咨询 CTA |
| `/{locale}/about` | 公司介绍 | `GET /public/pages/{slug}`（slug=`about`，运营在后台富文本维护）+ 站点联系方式 |
| `/{locale}/products` | 产品中心 | `GET /public/products`（分页 + `group` 筛选） |
| `/{locale}/products/{slug}` | 产品详情 | `GET /public/products/{slug}`（图集 + 视频 + 特性 + 正文） |
| `/{locale}/articles`、`/{locale}/articles/{slug}` | 新闻中心与详情 | 沿用既有文章页 |
| `/{locale}/contact` | 联系我们 | 站点联系方式（系统参数）+ 邮箱/电话/地址 |

- **布局壳**：门户新增 `PortalLayout`（`SiteHeader` + 内容 + `SiteFooter` + 容器），所有页面共用；页脚导航取 `GET /public/navs?position=FOOTER`。
- **设计令牌**：`--vane-*` 扩充为颜色/间距/字号/圆角/阴影/容器宽度六组令牌，门户样式只允许引用令牌（对齐 ADR-014）。
- **组件**：`BannerCarousel`、`ProductCard`、`SectionHeading`、`MediaGallery`（图集 + 视频）、`SiteFooter`。
- **图片/视频 URL**：统一 `/api/v1/public/files/{fileId}`，要求文件 `visibility=PUBLIC`。

### 7. SEO

- 首页输出 `Organization` JSON-LD（含 `logo`、`sameAs`、`contactPoint`）；产品详情输出 `Product` + `BreadcrumbList`；文章沿用 `Article`。
- sitemap 纳入已发布产品页（`/{locale}/products/{slug}`）；产品列表页与筛选态用 `noindex,follow`（沿用 ADR-018 对列表页的约定）。

### 8. 示例内容（种子迁移）

新增 `V19__seed_portal_site.sql`：写入一个示例公司的公司简介页、产品 3 条（含特性与媒体占位）、轮播 2 条、页头/页脚导航、文章 3 篇与分类 2 个。种子内容使用「示例公司」措辞，运营可在上线前整体替换。

## 影响

| 项 | 影响 |

| 数据库 | 新增 5 张表（`cms_product`、`cms_product_i18n`、`cms_product_media`、`cms_nav_i18n`、`cms_banner_i18n`）；迁移 `V18__corporate_site.sql`（表结构）、`V19__seed_portal_site.sql`（示例内容） |
| 后端 | 新增产品领域服务与公开/后台接口；导航与轮播 DTO 扩展；文件白名单与体积上限调整；sitemap 纳入产品 |

| 门户 | 布局壳、页脚、设计令牌、首页重做、产品中心与详情、公司介绍与联系我们页、JSON-LD 扩展 |
| 测试 | 产品 CRUD 与发布可见性、公开产品接口、媒体整体替换、导航/轮播本地化文案、文件视频类型、门户新页面渲染与 SEO |

## 风险与取舍

- **视频只存原文件**：不做转码、码率自适应与播放器进度条拖拽（Range 支持留待后续）；大文件走本地磁盘存储，跨实例部署需自行换 S3（`FileStorage` 已抽象，本轮不实现 S3）。
- **`features` 用 jsonb**：牺牲关系查询能力，换取运营录入简单与前端渲染直接；需要按特性筛选时再拆表。
- **导航/轮播文案双轨**：i18n 行与 key 并存，运营需理解「留空回退 key」，在后台表单中以提示文案说明。
- **首页区块依赖运营填内容**：区块为空时自动隐藏，不显示空标题（与既有空态约定一致）。
