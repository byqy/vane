# ADR-010：一期实现 TOTP 多因素认证

| 项 | 值 |
|---|---|
| 状态 | 已接受 |
| 日期 | 2026-10-17 |
| 影响文档 | 03 §14、01 §10、02 ADM-02 |

## 背景

管理后台的账号安全是常见事故点。等保二级不强制双因素，等保三级要求，因此需要权衡一期投入。

## 选项

| 选项 | 成本 | 说明 |
|---|---|---|
| 只预留 | 低 | 表结构与接口留位，一期不实现 |
| TOTP 一期做 | 约 3–5 天 | 无外网依赖，管理员可选开启 |
| MFA + Passkey | 多 1–2 周 | 安全性最好，但账号恢复复杂 |

## 决策

- 一期实现 **TOTP**（RFC 6238），管理员**可选开启**，不强制
- 密钥加密存储、防重放、时钟容差 ±1 窗口、恢复码一次性
- 登录改为两步：密码通过后返回一次性 `mfaToken`，校验 TOTP 后才发 access
- 短信/邮箱 MFA 与 Passkey 一期只预留

## 影响

- 正面：显著提升管理员账号安全性；TOTP 不依赖任何外部服务
- 代价：用户多一步操作；需管理恢复码；服务器时间必须保持同步
