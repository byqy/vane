# ADR-009：国际化资源的存放位置

| 项 | 值 |
|---|---|
| 状态 | 已接受 |
| 日期 | 2026-10-17 |
| 影响文档 | 04 §2、04 §6 |

## 背景

国际化涉及三类内容，性质不同：界面文案（属于代码）、运营内容（属于数据）、翻译协作（属于流程）。

## 选项

| 选项 | 说明 |
|---|---|
| 全部放仓库文件 | 可评审、可 diff，但改文案要发版 |
| 全部放数据库 | 运营可改，但无评审、与代码不同步、首屏多一次请求 |
| 分而治之 | 按内容性质分别存放 |

## 决策

采用**分而治之**：

| 内容 | 存放位置 |
|---|---|
| UI 文案、校验消息、错误码文案 | 仓库资源文件 |
| 字典项、公告、内容页、邮件/短信模板 | 数据库，按 locale 分行 |
| 翻译协作 | 一期人工；预留 TMS 导入导出接口 |

## 影响

- 正面：文案变更可评审、可回滚；运营内容无需发版
- 代价：修改界面文案需要发布新版本
