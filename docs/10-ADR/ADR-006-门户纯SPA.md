# ADR-006：前台门户采用纯 SPA

| 项 | 值 |
|---|---|
| 状态 | 部分被 [ADR-017](ADR-017-门户SEO基础.md) 取代（渲染模式仍为 SPA，「门户不需要 SEO」的结论不再成立） |
| 日期 | 2026-10-17 |
| 影响文档 | 01 §4.2、04 |

## 背景

模板包含后台管理端与前台门户端。门户是否需要被搜索引擎收录，决定渲染模式。

## 选项

| 选项 | SEO | 部署 | 成本 |
|---|---|---|---|
| 纯 SPA | 弱 | 静态文件 + API | 最低 |
| SPA + 预渲染 | 好 | 静态文件 | 中 |
| Nuxt SSR | 最好 | 需常驻 Node 服务 | 高 |
| 后端模板 | 好 | 单体 jar | 高，技术栈分裂 |

## 决策

门户**不需要 SEO**，采用 **纯 SPA**（Vue 3 + Vite），与后台管理端同栈同构建方式。删除国际化规范中的 SEO 章节。

## 影响

- 正面：部署最简单，只需静态文件与后端 API；两端技术栈一致
- 代价：门户页面无法被搜索引擎有效收录；若未来需要 SEO，需引入预渲染或 SSR
