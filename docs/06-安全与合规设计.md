## 1. 目标与范围

| 项 | 约定 |
|---|---|
| 目标基线 | **OWASP ASVS 5.0 L2** |
| 合规参照 | 等保 2.0 二级（客户要求三级时需追加主机与网络层控制） |
| 覆盖范围 | 应用层：认证、授权、输入输出、数据保护、审计、依赖供应链 |
| 不覆盖 | 主机加固、网络分区、WAF、DDoS（由部署方负责，本文给出要求） |

## 2. 威胁模型

| 威胁 | 典型场景 | 对策 | 落实位置 |
|---|---|---|---|
| 凭据窃取 | 撞库、暴力破解 | 弱密码校验、登录锁定、TOTP MFA、统一失败提示 | 01 §10、03 §14 |
| 会话劫持 | 令牌被窃 | refresh 存 HttpOnly Cookie、一次性轮换、复用即撤销整族 | 03 §14、ADR-007 |
| 垂直越权 | 普通用户调用管理员接口 | 权限点在服务端强制校验 | 02 §2 |
| 水平越权 | 跨组织读取他人数据 | 数据范围查询期统一注入 + 越权测试 | 02 §2、05 §7 |
| 注入 | SQL / 命令拼接 | JPA 参数化查询；禁止字符串拼接 SQL | 01 §7 |
| XSS | 富文本、文件名回显 | Vue 默认转义、富文本白名单净化、CSP | 本文 §5 |
| CSRF | 跨站伪造请求 | Bearer 传输无 CSRF 面；Cookie 端点校验 Origin + SameSite=Strict | 03 §14 |
| SSRF | 服务端代用户抓取 URL | 禁止用户提供任意 URL 的服务端抓取；必须抓取时走域名白名单 | 本文 §5 |
| 恶意文件 | 上传 WebShell / 存储型 XSS | 魔数校验、类型白名单、SVG 净化、目录不可执行 | 03 §15 |
| 路径穿越 | 文件名含 `../` | 存储 key 由服务端生成；文件名过滤 | 03 §15 |
| 信息泄露 | 错误堆栈、日志含敏感 | 统一 Problem Details、日志脱敏、返回字段最小化 | 03 §2 |
| 拒绝服务 | 大请求、慢接口 | 限流、请求体上限、超时、分页上限 | 03 §9 |
| 供应链 | 依赖漏洞、许可证风险 | 漏洞扫描、许可证门禁、SBOM | 01 §3、09 |

## 3. 认证安全

- 密码校验失败一律返回同一提示与同一错误码，**不区分**「账号不存在」与「密码错误」，避免账号枚举。
- 登录、重置密码、MFA 校验三条路径均按 `账号 + IP` 双维度计数并锁定（阈值与时长见 01 §10）。
- 密码重置令牌一次性、30 分钟有效、使用后立即失效。
- MFA 绑定必须密码二次确认；恢复码一次性且仅展示一次。
- access 令牌不落客户端持久存储；refresh 令牌只存哈希。

## 4. 授权安全

- 权限判定只在服务端进行，前端隐藏按钮**不是**安全边界。
- 数据范围在查询构建期统一注入；受控表须在 [05 §7](05-数据模型与数据字典.md) 登记。
- 列表、详情、导出、统计四类接口都必须受数据范围约束——导出是最容易被遗漏的越权通道。
- 全局豁免必须显式注解并记审计，豁免清单需评审。
- 越权测试覆盖每个受控表的四类接口（见 09）。

## 5. 输入与输出安全

| 面 | 要求 |
|---|---|
| 入参校验 | 所有写接口用 Bean Validation；长度、格式、枚举、范围必须显式声明 |
| 富文本 | 服务端白名单净化后入库；前端渲染仍走转义或受控渲染器 |
| 输出 | 默认 HTML 转义；`innerHTML` 仅用于已净化内容 |
| CSP | `default-src 'self'`；按需放开 `img-src`、`style-src`；禁止 `unsafe-eval` |
| 反序列化 | 禁用 Jackson 多态默认类型；不反序列化不可信类型信息 |
| 日志 | 过滤换行与转义序列，防日志注入 |
| SSRF | 服务端出站请求只允许白名单域名；禁止跟随重定向到内网 |
| 上传 | 校验真实类型（魔数）+ 扩展名白名单 + 大小上限 + 图片重编码 |

## 6. 密码与密钥

| 项 | 要求 |
|---|---|
| 密码存储 | Argon2id（首选）或 bcrypt cost ≥ 12 |
| 密码策略 | 最小长度可配置（默认 6，合规场景 ≥ 12）；弱密码表校验 |
| TOTP 密钥 | AES-256-GCM 加密入库，密文带密钥版本号 |
| 主密钥 | 环境变量或 KMS 注入；**不得**入库、不得进镜像 |
| 轮换 | 主密钥支持多版本并行解密，滚动重加密 |
| 凭据外泄响应 | 可强制下线全部会话（撤销令牌族）并强制改密 |

## 7. 传输与安全响应头

- TLS 1.2 及以上（优先 1.3）；HTTP 一律 301 跳转 HTTPS。
- 必须下发：`Strict-Transport-Security`、`Content-Security-Policy`、`X-Content-Type-Options: nosniff`、`Referrer-Policy`、`Permissions-Policy`、`frame-ancestors`（经 CSP）。
- Cookie：`Secure` + `HttpOnly` + `SameSite`；敏感 Cookie 使用 `__Host-` 前缀（要求 `Path=/`）。

## 8. 数据保护与个人信息

| 级别 | 示例 | 处理要求 |
|---|---|---|
| 公开 | 公告、内容页 | 可匿名读取 |
| 内部 | 系统参数、角色配置 | 登录 + 权限点 |
| 个人信息 | 姓名、手机号、邮箱 | 最小必要、按权限可见、日志与导出受控 |
| 敏感个人信息 | 身份证、健康、位置 | 默认不采集；确需采集须单独同意并加密存储 |

- **最小必要**：字段设计阶段即确认用途，不采集无用途字段。
- **展示脱敏**：手机号、邮箱、身份证在列表与详情默认脱敏，单独权限点才可查看完整值。
- **日志**：不得记录密码、令牌、完整身份证与手机号。
- **导出**：导出属高风险操作，需独立权限点、记录审计、限制条数。
- **删除**：账号注销走软删除并匿名化关联展示信息；删除请求需可追溯。
- **保存期限**：业务数据与日志按客户政策设定，到期归档或删除。

## 9. 审计

- 审计范围：登录、登出、权限变更、用户与角色变更、配置变更、数据导出、文件下载、敏感数据查看。
- 操作日志分两级：所有写操作记录目标对象与上下文（目标类型/ID/名称快照、HTTP 状态、UA、组织、影响条数）；
  用户、角色/授权、系统参数、短信服务商等关键操作额外记录字段级 `before/after`（白名单，敏感字段恒为 `***`）。
- 审计记录**只增不改不删**；应用账号仅授予 `sys_oper_log` 的 INSERT / SELECT，不授予 UPDATE / DELETE；
  清理走独立任务与运维账号。
- 保留期默认 **730 天**（不低于等保要求的 6 个月），由 `audit-retention` 任务清理，清理前归档。
- 审计记录包含操作人、动作、对象、结果、HTTP 状态、IP、UA、`traceId`、时间；
  导出/下载动作本身也写入审计（`action=export|download` + 影响条数）。
- 脱敏：键名命中 password/secret/token/accessKey 等恒为 `***`；手机号、邮箱、身份证号按值掩码；
  入参与变更快照有大小上限。



## 10. 合规

| 法规 / 标准 | 要求 | 落实 |
|---|---|---|
| 个人信息保护法 | 告知同意、最小必要、单独同意（敏感）、删除权、可携带权 | 隐私政策、字段控制、注销与导出 |
| 数据安全法 | 分类分级、风险监测、事件处置 | 本文 §8、§9 |
| 等保 2.0 二级 | 身份鉴别、访问控制、安全审计、数据完整性 | 本文 §3–§9 |
| GDPR（参照） | 数据最小化、被遗忘权、处理记录 | 若服务海外客户时评估 |
| 开源许可 | 仅宽松许可；黑名单阻断 | 01 §3 |

## 11. ASVS L2 对照（节选）

| ASVS 类别 | 关键要求 | 落实情况 |
|---|---|---|
| 认证 | 密码强度、防暴力破解、MFA 可选 | 01 §10、03 §14 |
| 会话 | 令牌随机性、撤销、超时 | ADR-007 |
| 访问控制 | 服务端强制、最小权限、数据范围 | 02 §2 |
| 输入验证 | 服务端校验、白名单 | 本文 §5 |
| 密码学 | 标准算法、密钥管理 | 本文 §6 |
| 错误处理 | 不泄露内部信息 | 03 §2 |
| 数据保护 | 敏感数据不缓存、不落日志 | 本文 §8 |
| 通信 | TLS、HSTS | 本文 §7 |
| 文件 | 类型校验、防 XSS | 03 §15 |

## 12. 安全测试与门禁

| 项 | 要求 |
|---|---|
| 依赖漏洞 | 高危即阻断（CI） |
| 许可证 | 黑名单阻断（CI） |
| 越权测试 | 每个受控表覆盖列表 / 详情 / 导出 / 统计 |
| 上传测试 | 伪造扩展名、超大文件、SVG 脚本、双扩展名 |
| 认证测试 | 锁定、令牌重放、复用检测、MFA 绕过 |
| 渗透测试 | 首次上线前执行一次；重大版本变更后复测 |
| 漏洞响应 | 高危 24 小时、中危 7 天、低危 30 天 |

## 13. 与决策的对应
