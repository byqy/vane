# vane 文档索引

## 文档治理

- **单一权威**：同一主题只在一份文档定义，其余引用。技术栈与版本以 01 为准，HTTP 契约以 03 为准，表结构以 05 为准。
- **决策留痕**：设计选择记录为 ADR；已接受的结论不直接修改，结论变化时新建 ADR 并标注取代关系。
- **只写当前状态**：文档不记录变更历史，历史由版本控制承担。
